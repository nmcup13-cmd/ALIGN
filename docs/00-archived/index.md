# 00 - Archived

เก็บเอกสารที่ **เลิกใช้งานแล้ว** เช่น

- เอกสารเวอร์ชันเก่าที่ถูกแทนที่ด้วยเวอร์ชันใหม่
- แผนงาน/ฟีเจอร์ที่เคยเสนอแต่ถูกยกเลิกหรือเปลี่ยนทิศทาง
- บันทึกการตัดสินใจเก่าที่ไม่มีผลบังคับใช้แล้ว แต่ยังมีคุณค่าในการอ้างอิงย้อนหลัง

> อย่าลบเอกสารออกจากโปรเจกต์โดยตรง ให้ย้ายมาเก็บไว้ที่นี่แทน เพื่อรักษาประวัติความเป็นมาของการตัดสินใจ
