# ข้อมูลหลัก PLO และรายวิชา — หลักสูตร 2565 และ 2570

เอกสารนี้เก็บ **ข้อมูลจริง** ของ PLO และรายวิชาทั้งสองหลักสูตร (สาขา New Media Communication) ที่ผู้ใช้ระบบ (อาจารย์ผู้สอน) จะเข้ามาเลือกใช้ในการตั้งค่า CLO/PLO ตาม Epic E1 (AB-01, AB-02) — คัดลอกมาจากเอกสารหลักสูตรจริงของสาขา (มคอ.2) แยกเป็นสองส่วนตามกลุ่มหลักสูตรอย่างเคร่งครัด **ห้าม merge ข้อมูลข้ามหลักสูตร** ตามกฎที่ระบุไว้ทั้งใน [[requirement-align|requirement-align]] และ [[../../02-design/02-technical/align-technical-design|align-technical-design]]

**สถานะ**: ข้อมูลอ้างอิงจริง (ไม่ใช่ข้อมูลตัวอย่างสำหรับทดสอบ — ข้อมูลทดสอบแยกอยู่ที่ [[../../03-testing/01-test-plan/test-plan-align|test-plan-align]] §3) ใช้เป็น seed data ตอนสร้างระบบจริงตาม schema `curriculum`/`plo`/`course` ใน align-technical-design.md §2.1, §2.2, §2.5

**หมายเหตุสำคัญ**: เอกสารนี้ให้แค่ **PLO และรายชื่อวิชา** เท่านั้น ยังไม่มี CLO ของแต่ละวิชา เพราะตามสเปค (AB-02) CLO เป็นข้อมูลที่**อาจารย์ผู้สอนแต่ละคนป้อนเอง**ต่อรายวิชาที่ตนรับผิดชอบ ไม่ใช่ข้อมูลกลางที่ตั้งไว้ล่วงหน้า
