# Task Breakdown: ระบบติดตามความสอดคล้อง CLO/PLO (ALIGN)

แตกมาจาก [[../02-plan/product-backlog|product-backlog]] โดยแตก User Story แต่ละข้อ (AB-01 ถึง AB-27) เป็นงานย่อยระดับที่ลงมือทำได้จริง (dev task) ทุกงานยังไม่เริ่มดำเนินการ

หมายเหตุ: งานที่เกี่ยวกับกลุ่มหลักสูตร 2565/2570 (การแยกข้อมูล การ validate ห้ามข้ามกลุ่ม) เป็นประเด็นที่ตัดผ่านหลาย Epic — ดูคอลัมน์ "หมายเหตุ" สำหรับ dependency ระหว่างงาน

หมายเหตุ (อัปเดต): ตาม product-backlog ฉบับล่าสุด — course syllabus เป็นข้อมูลหลักใหม่ (AB-19), สูตร % ความสอดคล้องเปลี่ยนเป็นสัดส่วน CLO ที่แมทช์ต่อ CLO ทั้งหมดของวิชา (AB-20) ร่วมกับค่าความถี่ที่แมทช์ (AB-21), และเพิ่มการวิเคราะห์ gap เทียบ syllabus (AB-22) ที่แสดงผลในแดชบอร์ด (AB-23) — งานที่ผูกกับ AB-08/AB-10/AB-11/AB-16 ถูกปรับปรุงข้อความในตำแหน่งเดิม (คง ID เดิม) ส่วนงานใหม่เริ่มที่ T-064

หมายเหตุ (อัปเดต — เพิ่ม Epic E6): product-backlog เพิ่ม **E6 — สมัครและอนุมัติบัญชีผู้ใช้** (AB-24 ถึง AB-27) พร้อมกฎทางธุรกิจ #6 (บัญชีที่ยังไม่อนุมัติต้องเข้าถึงข้อมูล/ฟีเจอร์ใดๆของระบบไม่ได้เลย) งานย่อยของ AB-24–AB-27 เริ่มที่ T-082 อ้างอิงชุดฟิลด์ฟอร์มสมัครสมาชิกและชื่อหน้าจอจาก [[../../02-design/01-prototypes/align-interactive-prototype|align-interactive-prototype]] (M-SignUp.dc.html, M-PendingApproval.dc.html, M-AdminApproveAccounts.dc.html) — เอกสารต้นแบบนั้นระบุไว้เองว่าชุดฟิลด์เป็น **ข้อสมมติที่ยังไม่ยืนยัน** (ดูหมายเหตุท้ายเอกสารนี้)

หมายเหตุ (อัปเดต — ตัดออก, 2026-08-20): งาน **T-062, T-063 (ผูกกับ AB-18)** ถูกย้ายไปที่ [[../../00-archived/backlog-ab-18-area-of-improvement-toggle|00-archived]] แล้ว เนื่องจากผู้ใช้ยืนยันว่าไม่ต้องการฟีเจอร์ตัวเลือกรวม/ไม่รวม Area of Improvement ตอน export — เอกสาร Word export ต้องแสดง Area of Improvement เสมอ (ดู AB-16/T-056–T-058) ไม่มี toggle ให้เลือกอีกต่อไป ไม่ต้องดำเนินการ T-062/T-063 ใดๆ

หมายเหตุ (อัปเดต — เพิ่มคอลัมน์ "Phase", 2026-08-23): เพิ่มคอลัมน์ **Phase** ต่อจาก [[../02-plan/release-plan|release-plan]] ที่จัดกลุ่ม Task ทั้งหมดเข้า 6 Phase ตามลำดับ dependency-first (Phase 1 = E6, Phase 2 = E1, Phase 3 = E2, Phase 4 = E3, Phase 5 = E4, Phase 6 = E5) — ค่าในคอลัมน์เดิม (ID, PB Ref, Task, Status, หมายเหตุ) ไม่มีการแก้ไขใดๆ ดูเหตุผลการจัดกลุ่มและข้อยกเว้น (T-087, T-103, T-106, T-113) ฉบับเต็มที่ [[../02-plan/release-plan|release-plan]] §3–4
