## ปิดคำถามเปิดใน test-plan-align.md §6 (5 จาก 7 ข้อ)

ยืนยันกับผู้ใช้แล้วปรับ schema/API/backlog/test case ให้ตรงกัน:

- **§6.1 ความถี่ที่แมทช์**: % = (จำนวนครั้งที่แมทช์ CLO นั้น) ÷ (จำนวนครั้งสอนทั้งหมด) แสดงคู่กับจำนวนดิบ ไม่รวมกับ % coverage เป็นตัวเลขเดียว
- **§6.2 โครงสร้าง Course Syllabus**: แยก 2 ส่วน — ไฟล์ทางการที่บังคับอัปโหลด (`origin_file_ref`, อ้างอิงเฉยๆ ไม่ parse) + หัวข้อรายสัปดาห์แบบสั้นที่กรอกแยก (`content`, ใช้เทียบ gap อัตโนมัติจริง)
- **§6.3 AB-16 "3 ระดับ"**: ไม่มีระดับ เปลี่ยนเป็นคำบรรยายข้อความอิสระ
- **§6.5 ฟิลด์ฟอร์มสมัครสมาชิก**: ชื่อ/อีเมล/รหัสผ่านเท่านั้น **ไม่มีฟิลด์สังกัด/ภาควิชา** (ระบบให้บริการเฉพาะสาขา New Media Communication สาขาเดียว) — ลบฟิลด์นี้ออกจากทุกต้นแบบ (connected HTML, เอกสารข้อความ, `M-SignUp.dc.html`, `M-AdminApproveAccounts.dc.html`, `canvas.json`) แล้ว re-seed/republish Design Canvas
- **§6.6 rejection_reason**: ไม่บังคับกรอก (เหตุผลปฏิเสธในทางปฏิบัติมีกรณีเดียว)

รัน `test-designer` ตรวจ trace backlog ↔ test case ทั้ง 6 Epic/27 story — ผลคือ **ครอบคลุม 100%** ก่อนเริ่มปิดคำถามเปิดข้างต้น (129 test case) และเพิ่มเป็น 137 test case หลังปิดคำถาม
