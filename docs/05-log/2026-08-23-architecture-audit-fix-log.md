# 2026-08-23: แก้ไขข้ออ้างอิงสเปคที่ผิดใน `align-high-level-architecture.md` (§4.2 exclusive role)

## บริบท

การรัน `audit-align-docs` พบว่า [[../02-design/02-technical/align-high-level-architecture|align-high-level-architecture]] §4.2 (บรรทัดเรื่อง "บัญชีแยกกันเด็ดขาด") อ้างว่ากฎ exclusive-role (ผู้ใช้ 1 คนถือได้เพียงบทบาทเดียว ไม่มี multi-role) มาจาก "ตามที่ระบุในสเปค" — ตรวจสอบ [[../01-requirements/01-spec/requirement-align|requirement-align]] แล้วพบว่า **ไม่มีข้อความนี้อยู่จริงในสเปค** เป็นข้อสันนิษฐานของเอกสาร architecture เองที่อ้างที่มาผิด

## สิ่งที่ยืนยันกับผู้ใช้แล้ว

ผู้ใช้ยืนยันว่า **exclusive-role ยังคงเป็นกฎการออกแบบจริงของระบบ** (บัญชีแยกกันเด็ดขาด, ไม่มีผู้ใช้คนเดียวถือสองบทบาทพร้อมกัน) — แต่ที่มาคือ**การตัดสินใจเชิงออกแบบที่ยืนยันในเซสชันนี้ (2026-08-23)** ไม่ใช่ข้อความที่มีอยู่ในสเปคเดิมโดยตรง เนื้อหาเรื่อง Access Gate แบบ exclusive role จึงยังคงไว้เหมือนเดิมทุกประการ มีการแก้ไขเฉพาะที่มา/การอ้างอิงเท่านั้น

## เอกสารที่แก้ไข

- `docs/02-design/02-technical/align-high-level-architecture.md` §4.2 — เปลี่ยนข้อความจาก "...พร้อมกันตามที่ระบุในสเปค — เอกสารนี้จึงออกแบบ..." เป็น "...พร้อมกัน — เป็นการตัดสินใจเชิงออกแบบที่ยืนยันกับผู้ใช้แล้วเมื่อ 2026-08-23 (ไม่ได้ระบุไว้ในสเปคเดิมโดยตรง) เอกสารนี้จึงออกแบบ..." ไม่มีการแก้ไขเนื้อหาอื่นในเอกสาร
