# 2026-08-23: รัน `audit-align-docs` ทั้งระบบ — พบ 8 finding, แก้ครบ 8, ยืนยัน 1 เรื่องธุรกิจ

## บริบท

รัน audit ครอบคลุมทุกโฟลเดอร์ (01-requirements ถึง 05-log) เทียบกับ `CLAUDE.md` เป็นไม้บรรทัด พบ 8 finding: 🔴 Contradiction 3, 🟡 Gap 4, 🔵 Orphaned reference 1

## Finding ที่แก้แล้ว (7/8)

1. **นิยาม "ความถี่ที่แมทช์" (AB-21)** — `align-technical-design.md §2.10/§4.2` ยังเขียนว่า "ยังไม่ฟันธง" ทั้งที่ `product-backlog.md` ยืนยันสูตรไปแล้วตั้งแต่ 2026-08-20 และ schema เดิมขาดฟิลด์ตัวหาร/ผลลัพธ์ % — แก้ทั้ง `align-technical-design.md` และ `align-api-schema-design.md §3.10` ให้ตรงกัน เพิ่มฟิลด์ `total_teaching_record_count` และ `match_frequency_percent`
2. **`release-plan.md` ขัดแย้งกับตัวเอง** — §2.2 ระบุ T-113 เป็น Task ยกเว้นข้าม Phase ทั้งที่ §4 ในไฟล์เดียวกันแก้ไขตัวเองว่าไม่ใช่ (ตัวจริงคือ T-106) — แก้ §2.2 ให้ตรงกับ §4 และ `task-breakdown.md`
3. **อ้างว่า "สเปคระบุ" ห้าม exclusive-role ทั้งที่ไม่มีข้อความนี้ในสเปคจริง** — ผู้ใช้ยืนยันว่า exclusive-role ยังเป็นกฎจริง แต่แก้ที่มาการอ้างอิงใน `align-high-level-architecture.md §4.2` (ดูรายละเอียดที่ [[2026-08-23-architecture-audit-fix-log|log แยกของ finding นี้]])
4. **`align-app-screens.md` ย่อหน้าเปิดไม่รวม AB-24/25/27** หลังเพิ่ม Epic E6 — แก้ตัวเลขให้ตรงกับตาราง Traceability และ index.md
5. **`align-tech-stack.md §5` แนะนำงานที่ทำสำเร็จไปแล้ว** — แก้เป็นข้อความยืนยันสถานะเสร็จสิ้นแทนคำแนะนำเชิง action
6. **Anchor link ผิดรูปแบบ** ใน `e4-dashboard-alerts.md` (ใช้ GitHub slug แทนข้อความ heading เต็มแบบ Obsidian) — แก้ให้ตรงรูปแบบเดียวกับจุดอื่นในโปรเจกต์
7. **ไม่มี log สำหรับการสร้างเอกสาร conceptual 3 ฉบับ และการปิด soft-delete/เพิ่ม tech-stack-advisor** — เขียนย้อนหลังที่ [[2026-08-23-conceptual-design-docs-log|conceptual-design-docs-log]] และ [[2026-08-23-soft-delete-and-tech-stack-log|soft-delete-and-tech-stack-log]]

## Finding #8 — แก้ผ่าน `design` skill แยก context

8. **ต้นแบบที่คลิกได้ (Design Canvas + connected mobile prototype) ยังไม่มีปุ่มลบ CLO/Confirm Dialog** ตามที่ `align-app-screens.md` (source of truth) มีอยู่แล้ว — เพิ่มปุ่มลบ CLO + Confirm Dialog ให้ `CourseManage.dc.html`, `M-CourseManage.dc.html`, และ `align-connected-mobile-prototype.html` แล้ว ทดสอบ flow เปิด/ยกเลิก/ยืนยันลบจริงผ่าน local server ผ่านหมด — republish ลิงก์ Artifact เรียบร้อยแล้ว (สกัดสถานะที่เผยแพร่อยู่มาตรวจก่อน ยืนยันตรงกับ git เป๊ะ ไม่มีการแก้ผ่าน GUI ค้างที่จะถูกทับ) ดู [[../02-design/01-prototypes/align-interactive-prototype|align-interactive-prototype]] หมายเหตุล่าสุด
