# 2026-09-06: ปิด audit finding — แก้ป้ายกำกับสถานะตกค้าง (stale status) ใน align-api-schema-design.md

## บริบท

Audit แบบ read-only ล่าสุดพบ 2 จุดที่ [[../02-design/02-technical/align-api-schema-design|align-api-schema-design]] มีป้ายกำกับสถานะที่ตกยุค (cosmetic เท่านั้น การตัดสินใจจริงถูกต้อง/ปิดครบแล้ว ไม่ใช่งานออกแบบใหม่):

**A. ขัดแย้งกันเองในเอกสาร**: หัวเอกสาร (บรรทัด ~5) และป้ายกำกับที่ §2.2/§3.2/§3.9 ยังคงเขียนว่า "ข้อเสนอ — ยังไม่ยืนยัน" สำหรับ (1) โครงสร้าง collection hierarchy และ (2) รูปแบบ document ID ของ `ai_match_result` ทั้งที่ §5.6 และ §5.7 ของเอกสารเดียวกันได้ระบุไว้แล้วว่า **"ยืนยันแล้ว 2026-09-05"** ทั้งสองประเด็น (เลือก Hybrid/ทางเลือกที่ 3 และแนวทาง A ตามลำดับ — ตรงกับ default ที่เอกสารใช้อยู่แล้วทั้งฉบับ ไม่มีอะไรเปลี่ยน)

**B. อ้างอิง align-technical-design.md ผิดยุค**: บรรทัด ~11 และ §6 ของเอกสารนี้ยังระบุว่า align-technical-design.md §2/§3 "ยังเป็นโมเดลเชิงสัมพันธ์เดิม (PostgreSQL)" และเกิดความไม่สอดคล้องภายในเอกสารนั้น — ข้อความนี้เป็นจริง ณ วันที่เขียนครั้งแรก (2026-09-05) แต่ตกยุคแล้ว เพราะ [[2026-09-06-technical-design-firestore-conversion-completion-log|บันทึกก่อนหน้า]] ยืนยันว่า align-technical-design.md §2 (ทั้ง §2.1–§2.15 และไดอะแกรมท้าย §2) และ §3 ถูกแปลงเป็น Firestore ครบทั้งหมดแล้ว และ `docs/02-design/02-technical/index.md` ก็สะท้อนสถานะปิดแล้วนี้อยู่ก่อนแล้ว

## สิ่งที่แก้ไข

แก้ไขเฉพาะป้ายกำกับ/สถานะใน `align-api-schema-design.md` — **ไม่แก้เนื้อหาการตัดสินใจ/ฟิลด์/collection hierarchy ใดๆ** (ของเดิมถูกต้องอยู่แล้ว):

1. หมายเหตุหัวเอกสาร (เดิม "สิ่งที่ยังไม่ยืนยันจากการปรับรอบนี้") → เปลี่ยนเป็น "[ปิดแล้ว 2026-09-06]" พร้อมสรุปว่าทั้ง 2 ประเด็นถูกยืนยันแล้วเมื่อ 2026-09-05 และป้ายกำกับที่ตกค้างถูกแก้ในรอบนี้
2. บรรทัดความสัมพันธ์กับ align-technical-design.md (~บรรทัด 11) → ปรับให้ระบุว่าสถานะ "ยังไม่ถูกปรับ" เป็นสถานะเดิม ณ 2026-09-05 ที่ปิดแล้ว พร้อมลิงก์ไปยัง [[2026-09-06-technical-design-firestore-conversion-completion-log|บันทึกที่ปิด finding นี้]]
3. หัวข้อ 2.2 (Collection Hierarchy) → ป้ายกำกับเปลี่ยนจาก "ข้อเสนอ — ยังไม่ยืนยัน" เป็น "ยืนยันแล้ว 2026-09-05: แนวทาง Hybrid (ทางเลือกที่ 3)"
4. ตาราง document-ID strategy ใน §3.2 (แถว `ai_match_result`) และ §3.9 (แถว document id) → ป้ายกำกับเปลี่ยนเป็น "ยืนยันแล้ว 2026-09-05: แนวทาง A"
5. §6 ("สิ่งที่ควรส่งต่อให้ technical-designer ปรับ") → เปลี่ยนหัวข้อเป็น "สิ่งที่เคยต้องส่งต่อ ... — [ปิดแล้ว 2026-09-06]" แยกเป็น "สถานะเดิม" (2026-09-05) กับ "สถานะปัจจุบัน (ปิดแล้ว)" พร้อม strikethrough รายการทั้ง 4 ข้อเดิมและกำกับว่า "แก้แล้ว" ทุกข้อ (ไม่ลบเนื้อหาเดิม เก็บไว้เพื่อ traceability)

## ผลกระทบ/สิ่งที่ต้องตรวจสอบต่อ
